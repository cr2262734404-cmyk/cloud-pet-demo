# 云朵宠物 · 商业 V1 手机 H5 Demo

手机浏览器打开：<https://cr2262734404-cmyk.github.io/cloud-pet-demo/>。二维码见 [`assets/access-qr.png`](assets/access-qr.png)。

顾客端、老板端、员工端共 54 个业务路由；顶部「H5 演示」切换角色，顶部季节标签切换四季与清晨、白天、夕阳、夜晚。春蓝、夏绿、秋金、冬冰蓝的场景、插画与玻璃组件属于同一套主题系统。场景保持用户指定的母图与已确认夏 B、秋 A 方案。

核心演示流程：顾客预约 → 老板确认与排期 → 员工接待、服务、完成 → 顾客查看手记/头像礼物 → 老板记录消费与经营归因。另有机会雷达、合规提醒、海报、客户与宠物档案、服务与人员设置及两家模拟门店。

本仓库根目录是 GitHub Pages 静态站；可维护源码在 [`source/`](source/)，恢复、构建、测试、已验证项目和限制见 [`FINAL_VALIDATION.md`](FINAL_VALIDATION.md)。页面有真实文字、按钮、表单和业务状态，不把整张参考稿作为点击热区。

这是静态 H5 演示，未作为微信小程序审核发布；数据只在当前浏览器内跨三端联动，不跨设备同步，也不发送真实消息或收款。Android 与 iPhone 物理设备仍需实际测试并记录，Chrome 手机尺寸模拟不能代替真机测试。
