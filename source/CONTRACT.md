# 云朵宠物 H5 Demo — shared implementation contract

Vanilla ES modules; Node built-in HTTP server, no production services. Root owns `dist/main.js`, `dist/ui.js`, `dist/styles.css`, HTML and assets. Engine agent owns `engine.mjs`, `server.mjs`, `test-engine.mjs`. Customer agent owns `dist/customer.js`. Business agent owns `dist/business.js`. Never modify other agent files without coordination.

Frontend modules export `renderCustomer(ctx)` / `renderBusiness(ctx)` returning HTML string and `handleCustomer(action, el, ctx)` / `handleBusiness(action, el, ctx)` returning true when handled, async allowed. Also optional `mountCustomer(ctx)` / `mountBusiness(ctx)` called after each render to add local listeners. ctx = {state, role, storeId, page, id, theme:{season,period}, ui, go(page,id), mutate(type,payload), refresh(), toast(message), modal(html), closeModal(), draft:{}}. `mutate` calls server then refreshes state but DOES NOT rerender; caller ctx.go/ctx.refresh. go renders. `draft` persistent object for flows.

Use `<button data-action="..." data-id="...">`; forms `<form data-action="..."><input name="...">`; handler reads `new FormData(el)` where el=form. Navigation `<button data-go="page" data-id="id">`. For main nav pages use `home, appointments, pets, profile` customer; `today, schedule, customers, results` owner; `work, history, tools` staff. Other pages at module discretion and document exported `customerRoutes` / `businessRoutes` arrays {page,title,id?} for screenshot QA. Pages requiring id use seed ids.

ui helpers: esc(s), icon(name,size=24), btn(label,action,opts={id,kind:'primary'|'secondary'|'ghost'|'danger',disabled}), tag(text,tone=''), empty(title,body,buttonHtml=''), section(title,rightHtml=''), field(label,name,value='',type='text',attrs=''), petAvatar(pet,size=56), money(number), date(iso), timeRange(appointment), status(status), downloadPoster({title,subtitle,pet,footer,theme}), copy(text). Helpers return strings except downloadPoster/copy promises. Use plain standard CSS classes: .page .page-head .eyebrow .glass .card .stack .row .between .muted .small .grid2 .grid3 .list .list-item .button .primary .secondary .ghost .danger .field .input .chip .selected .avatar .section-title .amount .notice .success .error .stepper .slot .tabs .portrait .report-hero .report-body .toolbar .timeline .metric .action-grid. Page root can be nested in `<div class="page">`; home hero is special root no .page.

GET /api/state?store=cloud&role=customer returns state filtered by role. POST /api/action JSON {store,role,type,payload}. Store ids cloud, meadow. Demo customer always c1, demo staff e1, server enforces scope, role selectable intentionally demo not authentication. Poll UI every 5s when no active form/modal to sync devices.

State shape {store:{id,name,subtitle,phone,address,hours,logo,theme},today:'YYYY-MM-DD',customers:[{id,name,phone,consent,marketing,contactStatus,cooldownUntil,notes,visits}],pets:[{id,customerId,name,breed,sex,birthday,weight,neutered,careNotes,allergies,photo,deceased}],services:[{id,name,category,description,price,duration,species,employeeIds,enabled}],employees:[{id,name,skills,active}],appointments:[{id,customerId,petId,serviceId,employeeId,date,time,status,notes,opportunityId,amount}],reports:[{id,appointmentId,petId,customerId,employeeId,date,items:{fur,ears,nails},behavior,note,nextAdvice,viewed,status,beforePhoto,afterPhoto}],orders:[{id,appointmentId,amount,status,opportunityId,date}],opportunities:[{id,customerId,petId,serviceId,type,title,reason,estimate,priority,status,employeeId,contactedAt,appointmentId,blockedReason}],reminderRules:[{id,name,mode,channel,enabled,time,frequencyDays,quietStart,quietEnd}],reminderLogs:[{id,customerId,opportunityId,channel,status,reason,text,date}],gifts:[{id,petId,customerId,reportId,theme,status,photo}],posts:[],deviceTests:[],revision:number}. Seed c1 林女士, p1 糯米, p2 橘子, e1 小夏, s1 洗护造型. Customer may see only own items. Staff only assigned data and no aggregate financial totals.

Actions (payload): pet.save {id?,...fields}; customer.save {id?,...}; service.save {id?,...}; employee.save {id?,...}; store.save {...}; booking.create {petId,serviceId,employeeId,date,time,notes,opportunityId?}; booking.update {id,date?,time?,employeeId?,status?}; booking.cancel {id,reason}; booking.arrive {id}; booking.start {id}; service.complete {id,items,behavior,note,nextAdvice,beforePhoto?,afterPhoto?} produces report and unconfirmed order; order.confirm {id,amount}; report.save {id,...}; report.view {id}; gift.generate {petId,reportId,theme,fail?} preset simulated; gift.confirm {id}; opportunity.contact {id,text,channel:'manual'|'subscription'|'sms'} manual marks contacted, authorized simulated logs; opportunity.update {id,status,employeeId}; reminder.rule {id,...}; reminder.run {}; consent.update {marketing,consent}; post.save {template,title,subtitle,serviceId}; demo.reset {}; demo.scenario {name:'empty'|'full'|'normal'}; device.record {platform,device,browser,result,notes,checks}; all commands return {ok:true,state?,result:{id?,...}} or HTTP error {error,message}. Engine may support more, notify changes.

Business assumptions: appointments 09:00-18:00, 30 minute start intervals; compare service durations per employee; active skill matching; reject overlapping including race after refresh. booking states pending,confirmed,arrived,serving,completed,cancelled. Opportunity states new,contacted,booked,completed,paused,blocked. Only opportunity contacted then booking linked within 7 days, completed confirmed order qualifies attributed amount. Expected != booked != actual != attributed. Sensitive: marketing=false, cooldown, deceased exclude contact; duplicate frequency check; deceased pet remains excluded after family cooldown. All messages/payments/image generation clearly simulated; no real sending or payment.

Styles follow provided blue spring, green summer, champagne autumn, icy blue winter; period morning/day/sunset/night. No Emoji icons. Root will supply 16 independent scene tiles generated as one image atlas if available, four seasonal image icon assets, SVG utility icon system. Pet photo paths `/assets/pet-dog.jpg`, `/assets/pet-cat.jpg`, `/assets/pet-corgi.jpg`, `/assets/pet-poodle.jpg`. Distinct simulated pet photos, never brand mascot for pet records.
