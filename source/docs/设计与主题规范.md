# 云朵宠物 · 设计与主题规范

本文记录当前落地的 UI 规则与已知差距，供后续真实小程序开发接续；不把尚未完成的独立场景或真机检查标成完成。

## 已确认视觉选择

| 季节 | 当前选择 | 资源 | 基准时段 |
| --- | --- | --- | --- |
| 春 | 锁定用户原图构图 | `assets/locked-spring.webp` | 清晨 |
| 夏 | **B：树荫湖岸** | `assets/locked-summer-b.webp` | 白天 |
| 秋 | **A：夕阳坡地** | `assets/locked-autumn-a.webp` | 夕阳 |

旧场景拼图不作为最终首页背景。春冬不重新生成不同构图，优先保留天空、自然地貌、猫狗位置和宠物轮廓。原图中旧文字与控件覆盖的位置进行局部去字/背景过渡修复；`locked-manifest.json` 记录来源与修复范围，不能声称被遮住的风景像素本来就存在。

品牌场景宠物与顾客档案照片分开。顾客宠物使用独立模拟照片或用户上传照片；同品种扩展样例复用示例图时保留 `samplePhoto:true`，不伪装为多只真实宠物的唯一照片。

## 四时段与自动规则

自动模式使用 `Asia/Shanghai`：3–5 月春、6–8 月夏、9–11 月秋、其余冬；05:00–09:59 清晨、10:00–16:59 白天、17:00–18:59 夕阳、其余夜晚。手动选择季节或时段会退出自动模式。

当前由 worlds.js 显式映射16张场景资源：4张基准母图保持不变，另外12张是以对应母图为参考的独立时段延展。夏季固定B树荫湖岸，秋季固定A夕阳坡地；备选原稿仅在回看面板展示，不混入正式时段。

| 时段 | 场景变化 |
| --- | --- |
| 清晨 | 柔和低角度晨光、湖谷薄雾、舒展或探索的宠物 |
| 白天 | 通透蓝天与明确日光，没有明显月亮或星空 |
| 夕阳 | 暖色霞光、低太阳、长阴影和湖面暖反光 |
| 夜晚 | 独立星空月光、环境冷光与已有灯火，宠物休息或望景 |

已移除旧的整幅亮度滤镜和时段叠色。界面玻璃/文字仍随季节与夜间可读性切换，这是UI主题变化，不用于冒充场景变化。新图保持世界的相对布局、地形、已有建筑与猫狗身份；属于生成式时段延展，像素细节与宠物姿态会变化。全部原始参考图独立保留，高清生成源图及逐张核对记录保存在 references/time-extensions。

## 液态玻璃

通用卡片使用环境染色底、135° 白色高光、1px 半透明亮边、内高光与轻柔外阴影。基础模糊为 15px、饱和度 1.13；导航模糊为 22px、饱和度 1.2。大面积卡片避免多层重复高斯模糊。

首页预约卡额外采样同一原场景作为约 13px 模糊反射，叠加受控透明度；高光和暗部不能覆盖关键文字。夜晚玻璃保持蓝色/季节环境染色，正文采用浅色。轻量模式关闭昂贵模糊、动画和额外背景反射，改为稳定可读的实色层；不支持 `backdrop-filter` 的浏览器有背景降级。

当前通用圆角为 24px，首页预约卡约 23px，底部导航约 29px，弹层上角 30px，输入框 12px。圆角随组件尺度变化，避免所有对象统一成巨大胶囊。

## 图标与真实照片

首页服务、手记、联系和底部导航优先采用参考图提取的原有可爱图标。基础业务操作使用统一 24×24 SVG 线性图标，不使用 Emoji 代替图标。四季入口应保持接近的占地与视觉重量，联系门店不因建筑细节变大。

宠物照片使用 `object-fit:cover` 和稳定比例，不拉伸。档案详情、报告前后图、礼物原图与海报选宠使用同一宠物记录。上传图在浏览器压缩后保存，仍超出引擎限制时应明确报错，不截断数据。

## 手机布局与排版

- 主容器最大宽度 480px，以手机单列为核心；桌面只加辅助说明。
- 通用页面水平间距约 21px，小屏收至 16px；卡片内边距约 20px，小屏 16px。
- 系统中文字体优先 PingFang SC、Microsoft YaHei、Noto Sans CJK SC；正文约 15px，主要输入文字 16px，页面标题 25–27px。
- 主要按钮最低高度约 46px；首页主按钮约 42px；导航点击区至少约 58px 高。较小辅助入口必须继续检查真实触控可用性。
- 顶部使用 `safe-area-inset-top`，底部导航以 `max(12px, safe-area-inset-bottom)` 定位。内容区应为固定导航保留空间。
- 长中文名称、金额、备注和海报文案应换行；不允许以隐藏溢出掩盖丢失内容。

当前首页在原图上下文内重建文字和控件，场景保持固定构图。不同屏幕高度下“首屏完整展示”与原图比例存在取舍，应通过实际设备检查最近护理卡和导航边界，避免仅凭一个模拟尺寸定稿。

## 动效、可访问与导出

按钮按下采用轻微缩放，颜色切换约 0.2 秒。遵循 `prefers-reduced-motion`；轻量模式关闭动画。键盘焦点有可见描边，弹层支持 Esc/关闭与焦点约束，主要表单使用原生必填与类型校验。

护理纪念图、主题卡、海报在 Canvas 本地生成，需检查长文案、换行、品牌名称和选宠照片与屏幕预览的一致性。手机保存方式包括预览长按、下载链接和浏览器支持时的系统分享；不能保证所有浏览器都有同样的分享能力。

本规范中的尺寸和参数是当前代码事实，不代表已通过 Android/iPhone 真机性能或可访问性认证。真实硬件尚未接入，本轮不再安排用户中途检查。

新版主题与视口验证见 theme-validation.json；逐张源图核对见 world-scene-validation.json。所有截图为桌面浏览器重新渲染，未宣称真实Android/iPhone硬件测试。
