## 本轮修复

- 已选有效时间后清理旧错误提示。
- 新增猫咪返回预约时，依据新宠物类型匹配服务，重置不适用的护理师和时间。
- 营业时间、起止时段使用引擎 openingHours，保留默认 09:00–18:00。
- 护理手记不将预约开始时间误称为完成时间。
- 导出时指定 report / gift 类型，避免使用默认营销模板。
- 服务标签窄屏换行，去除重复底部空白，修正预约进度条重复状态圆点。

仅修改顾客模块 `dist/customer.js` 与 `dist/customer.css`，未改动主路由、共用 UI 或引擎。JavaScript 语法检查通过。
