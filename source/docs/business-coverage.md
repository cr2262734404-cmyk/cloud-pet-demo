## 已处理的边界

- 不适合联系的宠物 / 顾客显示原因，并禁用相关联系入口。
- 已预约、完成或暂停的机会不允许创建重复预约；已有待确认预约优先进入原预约。
- 预约按宠物种类过滤服务、按技能过滤员工、按服务时长标识不可用时段。
- 表单保留浏览器 required / min / max 校验；服务端错误由主壳统一呈现。
- 员工手记护理项保存为中文记录，不保存 `true / false` 文案。
- 离世状态永久保留，已标记的复选框不能撤回；其他在世宠物可在家庭冷却结束后恢复资格。
- 无任务 / 无预约 / 无客户搜索结果 / 无报告 / 无礼物等有空状态与下一步入口。
- 导出和分享明确标记预设 / 模拟能力，不声称已完成支付、消息投递、小程序审核或生产授权。
